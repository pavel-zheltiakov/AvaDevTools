Avalonia 12 的 DevTools。
免费、进程内、一键打开。

Avalonia 12 移除了内置的 F12 工具。AvaDevTools 把它们带了回来 —— 检查器、 实时编辑器、样式、3D 视图、事件和日志 —— 全部打包在一个开源 NuGet 包里。

dotnet add package AvaDevTools
快速上手 查看功能

DevTools 应有的一切

接入一次，在任意窗口按 F12。

🌳

树检查器

可视化树与逻辑树，显示名称与样式类；高亮覆盖层带 margin/padding 色带；支持点击拾取元素。

✏️

实时属性编辑

类型化编辑器 —— 复选框、枚举下拉、扁平分段开关 —— 附加属性分组显示，无需重新编译即刻生效。

🎨

取色器

每个 Color 和画刷都有色板，并附带完整取色器。拖动即实时应用。

📐

布局盒模型

可交互的 margin / border / padding 色带，支持逐边编辑；尺寸、约束与对齐一目了然。

🧩

样式与值帧

所有生效的样式、主题与本地值，含 setter、优先级和激活状态。编辑即作为实时本地覆盖生效。

🧊

3D 分层视图

把窗口展开为带纹理的 3D 图层 —— 旋转、缩放、点击选中。支持可视化、合并或逻辑树粒度。

🔗

跳转到源码

元素、样式、绑定与 ViewModel 的 file:line。语法高亮的 XAML/C# 预览，一键跳转到编辑器。

⚡

事件检查器

从完整注册表中挑选路由事件，观察其路由完成时的来源、时间与最终 handled 状态。

📜

日志查看器

绑定错误、布局与属性系统消息 —— 无需 LogToTrace()。带过滤、批量刷新，杜绝反馈循环。

📊

渲染器叠加层

FPS 计数、布局/渲染耗时曲线与脏矩形闪烁，一个开关即可打开。

🕵️

每个值的来源

一眼看出取值来自默认、手动设置、样式、模板还是继承 —— 并可跳到祖先元素或设置它的那行 XAML。

🌒

IDE 风格深色界面

紧凑的 Rider/Unity 风格控件，只作用于工具窗口，绝不影响应用本身的主题。

快速开始

在 App.axaml.cs 里加两行 —— 仅 Debug 生效，Release 不包含任何内容。

public override void Initialize()
{
    AvaloniaXamlLoader.Load(this);
#if DEBUG
    this.AttachAvaDevTools();   // 任意窗口按 F12
#endif
}
