DevTools для Avalonia 12.
Безкоштовно. In-process. Одна клавіша.

Вбудованих інструментів F12 в Avalonia 12 більше немає. AvaDevTools повертає їх — інспектор, живі редактори, стилі, 3D-вигляд, події та логи — одним open-source NuGet-пакетом.

dotnet add package AvaDevTools
Почати Можливості

Усе, що очікуєш від DevTools

Підключіть один раз і натискайте F12 у будь-якому вікні.

🌳

Інспектор дерева

Візуальне та логічне дерево з іменами і класами стилів, підсвічування з зонами margin/padding та режим вибору елемента кліком.

✏️

Живе редагування властивостей

Типізовані редактори — чекбокси, списки enum, плоскі сегментні перемикачі — згруповані attached-властивості та миттєвий результат без перезбирання.

🎨

Палітра кольорів

Кожен Color і пензель має зразок кольору з повноцінним колірним пікером. Зміни застосовуються наживо.

📐

Боксова модель

Інтерактивні зони margin / border / padding із редагуванням кожної сторони, а також розміри, обмеження та вирівнювання.

🧩

Стилі та фрейми значень

Усі застосовані стилі, тема і локальні значення з сеттерами, пріоритетом та станом активності. Редагування — як живі локальні перевизначення.

🧊

3D-вигляд шарами

Ваше вікно як текстуровані шари у 3D — обертайте, масштабуйте, клікайте для вибору. Візуальне, згорнуте або логічне дерево.

🔗

Перехід до коду

file:line для елементів, стилів, біндінгів і в’ю-моделей. Підсвічені фрагменти XAML/C# та перехід у редактор одним кліком.

⚡

Інспектор подій

Обирайте routed-події з повного реєстру та спостерігайте: джерело, час і фінальний стан handled.

📜

Перегляд логів

Помилки біндінгів, layout і система властивостей — навіть без LogToTrace(). З фільтрами, батчингом і захистом від зациклення.

📊

Оверлеї рендерера

Лічильник FPS, графіки часу layout/render та підсвічування dirty-rect — одним перемикачем.

🕵️

Джерело кожного значення

Одразу видно: значення типове, задане вручну, зі стилю, шаблону чи успадковане — з переходом до предка або точного місця в XAML.

🌒

Темна тема в стилі IDE

Компактні елементи в дусі Rider/Unity, лише у вікні інструментів. Тема вашого застосунку не змінюється.

Швидкий старт

Два рядки в App.axaml.cs — лише в Debug, у Release нічого не потрапляє.

public override void Initialize()
{
    AvaloniaXamlLoader.Load(this);
#if DEBUG
    this.AttachAvaDevTools();   // F12 у будь-якому вікні
#endif
}
